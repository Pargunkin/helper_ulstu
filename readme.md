# ULSTU Helper

Telegram-бот для абитуриентов и первокурсников УлГТУ.

## Описание
Бот помогает:
- абитуриентам понять процесс поступления;
- первокурсникам ориентироваться в учёбе;
- получать ответы на частые вопросы через FAQ;
- обмениваться анонимными вопросами с разработчиками.

## Технологии
- Python 3.13
- aiogram 3
- Visual Studio / Git Bash

## Структура проекта
- `main.py` — точка входа
- `config.py` — загрузка и проверка конфигурации
- `logic.py` — логика меню и маршрутизация
- `anon.py` — анонимные вопросы
- `faq.py` — FAQ
- `commands.py` — команды бота
- `keyboards.py` — клавиатуры
- `utils.py` — вспомогательные функции
- `state.py` — состояние бота
- `console.py` — консольный вывод
- `images/` — изображения и баннеры
