## ✨ Возможности

### Для студентов

| Раздел | Что внутри |
| --- | --- |
| ❓ **FAQ** | 10 разделов: БРС, отчисление, академический отпуск, сленг, поиск друзей, места для учёбы |
| 📶 **Wi–Fi** | Пошаговая инструкция подключения к `USTU_CORP` для **Android**, **Windows** и **macOS**: шаги, прогресс, кнопки «Назад» и «Далее», разбор ошибок |
| 🏫 **Академический отпуск** | Основания, полный перечень документов, сроки рассмотрения, порядок оформления через ЦОС, контакты и адрес |
| 🎭 **Анонимные вопросы** | `/anon` включает режим, в котором сообщение уходит разработчикам без имени и профиля |
| 🎲 **Мелочи на день** | Цитата, факт об УлГТУ и программировании, погода по команде |

### Для разработчиков

Этот репозиторий можно взять как **готовый шаблон Telegram–бота на aiogram 3**. Здесь уже решены вещи, на которые обычно уходят дни:

- **Структура без свалки.** Контент, обработчики, клавиатуры и состояние разнесены по папкам: тексты FAQ и инструкций живут в `data/`, клавиатуры — в `services/`, обработчики только связывают их;
- **Кэш медиа в SQLite.** `file_id` отправленных фото сохраняются и переживают перезапуск сборки, поэтому бот не загружает одни и те же картинки заново. WAL–режим, upsert, удаление записей;
- **Обработка краевых случаев.** Подпись к альбому нельзя отредактировать в текст — для этого есть отдельный фолбэк: удалить и отправить новое сообщение. Если фото не отправилось, уходит текстовый вариант. Мусорные `callback_data` игнорируются, номера шагов зажимаются в диапазон;
- **Безопасные операции с Telegram.** Удаление прошлых сообщений, ответы на callback и отправка медиа обёрнуты в обработчики ошибок: сбой одного шага не роняет бота;
- **Чистое состояние.** `last_messages` хранит и одиночные сообщения, и альбомы; FSM сбрасывается при старте и возврате в меню;
- **Пошаговые инструкции как паттерн.** Готовая связка «**меню → выбор варианта → шаги с прогрессом**» — можно копировать под любой многошаговый сценарий;
- **Понятная конфигурация.** Свой разбор `.env` с кавычками, комментариями и `export`, понятная ошибка при отсутствии токена;
- **Консоль, которой приятно пользоваться.** Баннер, цветные логи с бейджами уровней, время обработки апдейтов, живая статус–панель с аптаймом и памятью;
- **Тексты проверены.** Инструкции сверены с официальными документами УлГТУ, ссылки ведут на первоисточники;
- **Актуальная обратная связь.** Наша команда поддерживает связь с желающими использовать проект — по крайней мере до четвёртого курса или отчисления)

<a name="quickstart"></a>

## 🚀 Быстрый старт

```bash
git clone https://github.com/Pargunkin/helper_ulstu.git
cd helper_ulstu

python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS

pip install aiogram aiohttp
```

Создай `.env` рядом с `readme.md`:

```env
BOT_TOKEN=токен_из_@BotFather
ADMIN_GROUP_ID=id_группы_для_анонимных_вопросов
```

Запуск:

```bash
python system/main.py
```
